## 2. Overleaf Upload Instructions

1. Go to [Overleaf](https://www.overleaf.com/) and click **New Project** $\to$ **Upload Project**.
2. Select `presentation/Seminar_Presentation_1.zip`.
3. Set the compiler to **pdfLaTeX** (default in Overleaf).
4. Click **Recompile**.
